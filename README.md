## 共通データ `data/country_panel.csv`

World Bank から取得した**国×年**のデータです。**5,859行・217か国・1995〜2021年。**

| 列 | 意味 | 単位 |
|---|---|---|
| `iso3` | 国コード（3文字） | — |
| `country` | 国名 | — |
| `region` | 地域区分 | **年によって変わりません** |
| `year` | 年 | 1995–2021 |
| `gdp_pc` | 一人当たりGDP | 2015年米ドル（実質） |
| `pop` | 人口 | 人 |
| `trade_pct_gdp` | 貿易額（輸出＋輸入） | 対GDP比・％ |
| `milex_pct_gdp` | 軍事支出 | 対GDP比・％ |
| `resource_rents` | 天然資源レント | 対GDP比・％ |
| `internet_pct` | インターネット利用者比率 | ％ |
| `life_exp` | 平均寿命 | 年 |
| `oda_pct_gni` | 受取ODA | 対GNI比・％ |
| `land_area` | 国土面積 | km² |

**欠測はばらばらに散らばっていません。** たとえば `milex_pct_gdp` は1,870行が欠測で、**軍隊を持たない国は最初から入っていません。** これは第8回で扱います。

## 守ってほしいこと

**1. `data/raw/` と `.env` は commit しない。** `.gitignore` に入れてあります。外さないでください。

**2. データを取ったら、必ずこの4つを印字する。**

```python
print(len(df), df.columns.tolist(), df['year'].min(), df['year'].max(), df.isna().sum())
```

行数・列名・期間・欠測数。**AIが「取得しました」と言っても、この4つを自分の目で見るまで、取得は終わっていません。**

**3. 氏名・学籍番号・メールアドレス・所属を、ファイルの中にもフォルダ名にも書かない。** 非公開リポジトリであっても書きません。提出物の識別は、リポジトリそのもので行います。

**4. AIは使って構いません。ただし、口頭で説明できることが条件です。** 節ごとの禁止はありません。使った範囲は `ai_log.md` と論文末尾の付録Aに正直に書いてください。**正直に書いたことで減点されることはありません。**
