## 自分と突き合わせる（5つ）

| | |
|---|---|
| ① **Yは同じか** | 同じ ・ 違う → |
| ② **Xは同じか** | 同じ ・ 違う → |
| ③ 分析単位・期間は同じか | 同じ ・ 違う → |
| ④ **結果の向きは同じか** | 同じ ・ 違う → |
| ⑤ **同じ／違うのは、なぜか** | |

**⑤がいちばん大事です。** ①〜④は事実の確認で、⑤だけが自分の考えです。

### ⑤は、3通りのどれか

- [ ] **A** 同じことを、別の対象で確かめている
- [ ] **B** 同じ問いに、別の答えが出そう → **なぜ違うのかの説明が要る**（対象・期間・手法）
- [ ] **C** その論文が扱っていない範囲を見ている（**いちばん多い**。限界の節から入ることが多い）
